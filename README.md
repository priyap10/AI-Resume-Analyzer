# AI Resume Analyzer

An AI-powered web application that analyzes a resume against a job description and provides an ATS score, skill gap analysis, resume improvement suggestions, and AI-generated interview questions.

## Features

- Upload Resume (PDF)
- ATS Compatibility Score
- Matched & Missing Skills
- Resume Improvement Suggestions
- Resume Summary
- AI-Generated Interview Questions

## Tech Stack

**Frontend**
- React.js
- Vite
- CSS
- Axios

**Backend**
- FastAPI
- Python
- Groq API (Llama 3.3 70B)
- PyPDF2

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
